# Mail server

`r820` runs Simple NixOS MailServer for `derezzed.info` and the following
additional domains:

- `fuwa.space`
- `cybal.org`
- `netrunner.dev`
- `glowrunner.network`
- `glowrunner.dev`
- `glowrunner.xyz`

The mail hostname is `mail.derezzed.info`. The initial mailbox is
`aljam@derezzed.info`. Role aliases on every domain forward to that mailbox.

## Services

| Service | Port | Purpose |
|---|---:|---|
| SMTP | 25 | Inbound mail from other MTAs. |
| Submission | 587 | Authenticated outbound mail submission. |
| IMAPS | 993 | Encrypted mailbox access. |

All outbound mail is relayed through SendPulse at `[smtp-pulse.com]:587`.

## Before first deployment

### 1. Create the SOPS secret file

Create `secrets/mail.yaml` and add an explicit creation rule for it in
`.sops.yaml`. Scope the rule to `aljam` and `r820`.

```bash
sops --editor vim secrets/mail.yaml
```

Use this structure:

```yaml
aljam-password-hash: ARGON2ID_PASSWORD_HASH
postfix-sasl-passwd: |
  [smtp-pulse.com]:587 SENDPULSE_LOGIN:SENDPULSE_PASSWORD
```

Generate the mailbox password hash with:

```bash
nix-shell -p mkpasswd --run 'mkpasswd -m yescrypt'
```

Copy the SendPulse SMTP login and password from **SMTP → Settings → General**.
Do not commit either value in plaintext.

### 2. Update the lockfile

After checking out this branch locally, refresh the new mailserver input:

```bash
nix flake lock --update-input mailserver
nix flake check --show-trace
```

Commit the updated `flake.lock` before merging. CI cannot evaluate the new
input until its lock entry exists.

### 3. Configure DNS

For every mail domain, add:

```text
MX    10 mail.derezzed.info.
TXT   "v=spf1 include:spf.sendpulse.com -all"
TXT   _dmarc "v=DMARC1; p=none; rua=mailto:postmaster@derezzed.info"
```

Also configure:

```text
A     mail.derezzed.info -> R820_PUBLIC_IPV4
PTR   R820_PUBLIC_IPV4 -> mail.derezzed.info
```

After the first deployment, publish the DKIM record generated by the mail
server for each domain.

### 4. Verify SendPulse senders

In SendPulse, verify `derezzed.info` and each additional sending domain.
Follow SendPulse's SPF and DKIM instructions. A relay credential can submit
mail, but SendPulse must authorize the sending domain.

## Deploy

```bash
nix run .#deploy -- r820
```

After deployment, inspect the generated DKIM records:

```bash
sudo systemctl status postfix dovecot rspamd
sudo grep -R 'DKIM' /var/lib/rspamd/dkim 2>/dev/null || true
```

Publish each DKIM public key in DNS, then wait for propagation.

## Validate

Send a test message from the server:

```bash
echo "Outbound relay test from r820" \
  | mail -s "r820 mail relay test" aljam@derezzed.info
```

Check delivery:

```bash
sudo tail -n 100 /var/log/mail.log
```

Verify:

- Postfix and Dovecot are active.
- The message is submitted to SendPulse over TLS.
- `aljam@derezzed.info` receives the message.
- IMAPS login works on port 993.
- SPF, DKIM, and DMARC checks pass for outbound mail.
- Ports 25, 587, and 993 are not proxied through HAProxy.

## Adding a mailbox

Add an entry under `mailserver.loginAccounts`, create its password hash in
`secrets/mail.yaml`, and rebuild `r820`.

## Adding a domain

Add the domain to `mailDomains`, add its MX, SPF, DKIM, and DMARC records, and
verify it in SendPulse. Keep one domain migration small enough to validate
before adding the next.
